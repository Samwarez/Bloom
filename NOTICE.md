# Notices

Bloom was separated from the PetalOS installer source at version 0.4.0.
Original project code and artwork have no blanket license grant assigned.
Public availability does not itself grant redistribution or modification rights.

Third-party components retain their existing licenses and notices. Portable
builds include Debian package copyright files under `runtime/usr/share/doc`,
common license texts under `runtime/usr/share/common-licenses`, and exact
package/version records in `portable.json`. Matching package sources are
available from Debian's public source archive services. Release automation
and the portable builder identify the distribution and included packages.

The shared PetalOS release/storage helpers and test sources are retained to
preserve the installer catalog and storage interfaces. The flower emblem is
the existing project artwork; its provenance is recorded with the asset.
